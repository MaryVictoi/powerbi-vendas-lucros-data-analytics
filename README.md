# Relatório de Vendas e Lucros com Data Analytics no Power BI 📊

## 📝 Descrição do Projeto
Este repositório contém o projeto prático **"Criando um Relatório Vendas e Lucros com Data Analytics com Power BI"**, desenvolvido como parte da formação **Power BI Analyst** da [DIO](https://www.dio.me/).

O objetivo deste desafio foi construir e otimizar um relatório financeiro, implementando análises com viés estatístico e foco em Data Analytics para apoiar a tomada de decisão executiva.

## 🎯 Principais Implementações e Análises
- **Análise Temporal e Tendências:** Acompanhamento da variação de lucros e vendas ao longo do tempo utilizando visuais nativos (gráficos de linha e área).
- **Distribuição e Exceções (Outliers):** Implementação de gráficos de dispersão (*Scatter plot*) para identificar anomalias e correlacionar as vendas com as margens de lucro.
- **Decomposição de Dados:** Uso do visual de **Árvore Hierárquica** (*Decomposition Tree*) para explorar de forma interativa os impulsionadores de resultados divididos por segmentos, produtos e regiões.
- **Análise Estatística Automatizada:** Aplicação do recurso nativo "Analisar" do Power BI para explicar matematicamente variações, aumentos e quedas nos dados financeiros.

## 🛠️ Tecnologias e Recursos Utilizados
- **Power BI Desktop**
- DAX (Data Analysis Expressions)
- Power Query (ETL)
- Storytelling de Dados e UX/UI para relatórios

## 📂 Como acessar o projeto
1. Faça o download do arquivo `.pbix` disponível neste repositório.
2. Certifique-se de ter o [Power BI Desktop](https://powerbi.microsoft.com/desktop/) instalado na sua máquina.
3. Abra o arquivo para interagir com os dashboards, filtros e visuais de análise.
